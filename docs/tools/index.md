# 工具使用指南

工具页关注可复现、可协作的学习工作流。

=== "版本控制"

    计划覆盖 Git 基础、分支、Pull Request 和冲突处理。

=== "写作"

    计划覆盖 Markdown、LaTeX、参考文献和可访问的图表。

=== "计算环境"

    计划覆盖 Python 虚拟环境、Notebook、依赖记录与数据路径。

## 一个可复制的检查命令

```bash
python -m pip install -r requirements.txt
mkdocs build --strict
```

代码块右上角提供复制按钮。新增工具教程时，请写明操作系统、工具版本和验证方式。
