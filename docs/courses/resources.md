## 按文件类型处理

- **PDF / 图片**：GitHub 通常可以预览；大文件建议下载。先确认著作权和传播范围。
- **Notebook / Python**：记录依赖、数据来源和运行环境，不运行不可信代码；输出中不得保留隐私数据。
- **PPT / Word / Excel**：通常下载后打开，网页索引应说明用途；含姓名、成绩或签名时不公开。
- **ZIP**：不直接嵌入或自动展开，先检查内容和恶意文件风险。
- **Markdown**：最适合转为网站正文，但仍须脱敏、拆除答案型内容并修正资源路径。
