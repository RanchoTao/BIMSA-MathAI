## 使用附件

- **PDF / 图片**：可在 GitHub 预览；大文件更适合下载后查看。
- **PPTX / DOCX / XLSX**：通常需要下载并使用相应办公软件打开。
- **IPYNB / 代码**：先检查依赖和数据来源，不运行不可信代码。
- **ZIP**：不在网页内展开；下载前确认来源和内容。
