# 课程知识库

课程区以“知识结构”为主，以“历史附件”为辅。仓库现有内容主要按学期归档，第一版不移动原文件，也不将每个附件塞进侧栏。

## 已发现的课程范围

| 方向 | 仓库中已有目录示例 | 当前状态 |
| --- | --- | --- |
| 数学基础 | 数学分析、离散数学、高等代数、概率统计 | 原始资料或占位目录 |
| 人工智能与数据 | 机器学习、数据挖掘、深度学习、自然语言处理 | 原始资料或占位目录 |
| 计算机基础 | 数据结构、操作系统、数据库、计算机网络 | 多数为待建设目录 |
| 数学与工程拓展 | 数学建模、随机过程、信号处理、自动控制 | 原始资料或待建设目录 |

完整的按学期清单与附件访问方式见[现有资料索引](resources.md)。清单只说明仓库中确有对应目录，不代表课程仍开设，也不构成官方课程安排。

## 建设方式

一门内容较多的课程建议逐步形成：课程主页、课程笔记、作业与练习方法、考试复盘、资源索引。新增课程页时使用仓库中的 [`templates/course-page.md`](https://github.com/RanchoTao/BIMSA-MathAI/blob/main/templates/course-page.md)。

!!! warning "资料边界"
    历史作业与考试材料必须脱敏并确认可传播。本站不收录以直接提交或作弊为目的的答案材料。
