# 课程地图

本页按仓库中**真实存在的目录**建立入口。目录存在只代表仓库留有资料或规划占位，不代表课程仍开设，也不提供教师、学分、考核等未经核验的信息。

!!! info "怎样判断状态"
    “有附件”表示除 `README` 外确有文件；“仅目录说明”表示目前只有简短 README，应由有真实经验的贡献者补充。原文件保持原路径，点击课程名在 GitHub 查看。

## 如何继续整理

优先为“有附件”的课程建立资料索引，再把有授权、已脱敏且具有长期价值的内容转写为 Markdown。课程主页可使用 [`templates/course-page.md`](https://github.com/RanchoTao/BIMSA-MathAI/blob/main/templates/course-page.md)，但不得根据文件名推断教学信息。
