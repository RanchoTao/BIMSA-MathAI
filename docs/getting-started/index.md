# 新生指南

欢迎来到中国人民大学中关村校区参加北京雁栖湖应用数学研究院数学与人工智能专业的学习！
新生指南主要介绍中关村校区的生活和总体学习生活安排的经验

## 从哪里开始

1. **核验信息**：课程安排、培养要求与行政事项以官方渠道为准。
2. **浏览知识页**：先看[课程知识库](../courses/index.md)的课程地图，不必从附件堆开始翻找。
3. **谨慎使用资料**：历史作业只能用于理解方法与复盘，不应直接复制提交。
4. **留下改进**：发现过时内容、失效链接或表述错误，可通过页面右上角编辑入口提交修订。
