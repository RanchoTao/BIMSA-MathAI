## 从哪里开始

<div class="bimsa-paths" markdown>
- **BIMSA 新生** → 从[新生指南](getting-started/)了解信息核验与资料边界。
- **数学方向学习者** → 在[课程地图](courses/)查找分析、代数、概率与离散数学资料。
- **人工智能方向学习者** → 从机器学习、数据挖掘和后续 AI 课程入口开始。
- **正在进行科研训练的学生** → 阅读[科研与写作](research/)的复现与记录框架。
- **想贡献资料的人** → 按[贡献指南](about/contributing/)修正错误、补充笔记或整理课程。
</div>

## 一起把资料变成知识

你可以修正一个链接、补全一段说明、把允许公开的笔记整理成 Markdown，或为一门真实课程建立清晰索引。每个小改动都应注明来源并通过严格构建。
