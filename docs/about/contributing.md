# 参与贡献

所有内容都由 Markdown 驱动，无需前端开发经验。完整规范见仓库根目录的 [CONTRIBUTING.md](https://github.com/RanchoTao/BIMSA-MathAI/blob/main/CONTRIBUTING.md)。

## 最短流程

1. Fork 仓库并创建主题分支。
2. 在 `docs/` 合适分类中新增或修改 Markdown。
3. 必要时更新 `mkdocs.yml`；不要把每个附件加入导航。
4. 本地运行 `mkdocs build --strict`。
5. 提交 Pull Request，说明来源、适用范围和合规检查。

!!! danger "提交前必须确认"
    不得上传隐私、受限传播或侵权内容；作业和考试资料必须脱敏；不要提交可直接用于作弊的答案型材料。
