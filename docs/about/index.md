# 关于 BIMSA MathAI Wiki

BIMSA MathAI Wiki 是一个由社区贡献、以 Markdown 驱动的非官方开放知识库。它尝试把分散的课程附件和个人经验逐步整理成有结构、可搜索、可持续修订的网页书。

## 原则

- **非官方**：不替代任何官方通知或教学要求。
- **渐进整理**：保留历史资料，不进行不可逆的大规模迁移。
- **正文与附件分层**：侧栏展示知识结构，原始资料通过索引访问。
- **可追溯与合规**：注明来源，尊重隐私、传播限制和知识产权。
